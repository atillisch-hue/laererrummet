# Lærerrummet

Et enkelt digitalt lærer- og elevrum til klasser, elever, opgaver og skriveskabeloner.

## Første version
- Flere klasser
- Elever pr. klasse
- Opret og administrér opgaver
- Automatisk skriveskabelon efter opgavetype
- Elevvisning med opgaver og skrivehjælp

Bygget med Next.js og TypeScript.
